## 对齐保证

**`video.mp4` 的第 N 帧 ↔ `frames.csv` 的第 N 行**，严格 1:1，已校验零错位。

`frames.csv` 的 `video_frame` 列为视频帧号（从 0 起），`frame_id` 从 1 起，
恒满足 `video_frame == frame_id - 1`。

视频容器标称 10 fps，但真实时刻以 `t_mono_ms`（单调时钟，从 0 起的毫秒）为准。
无线链路抖动会导致帧间隔非严格等距，需要精确时序时请用 `t_mono_ms`。

## 操控动作列（核心）

四轴杆量，取值范围 **−100 ~ +100**，语义与 Tello SDK `rc` 指令一致：

| 列 | 含义 | 正方向 |
|---|---|---|
| `act_roll` | 横滚（左右平移） | 右 |
| `act_pitch` | 俯仰（前后移动） | 前 |
| `act_throttle` | 油门（升降） | 上 |
| `act_yaw` | 偏航（原地转向） | 顺时针 |

本 episode 中 `act_roll` 恒为 0：漫游策略的安全约束禁止侧向平移。

### `ctrl_state`：动作来源

| 值 | 帧数 | 含义 |
|---|---|---|
| `WANDER_CRUISE` | 587 | 自动 · 随机直线巡航 |
| `WANDER_TURN` | 150 | 自动 · 原地转向 |
| `WANDER_VERIFY` | 69 | 自动 · 转向后悬停确认前方 |
| `MANUAL` | 54 | **人工接管**（操作员键盘打杆） |
| `HOVER` | 187 | 悬停 / 未挂载自动模式 |

只取人工示教数据请筛 `ctrl_state == 'MANUAL'`；
只取自动策略数据请排除 `MANUAL` 与 `HOVER`。

`meta.json` 中 `action_source: "mixed"` 即表示本回合两种来源并存。

## 采集说明

自动漫游策略基于单目深度估计（Depth Anything V2）判断前方通行性。

**已知局限**：单目深度对铁丝网这类稀疏栅格结构基本失效——透过网眼看到的是笼外
远景，模型会将其判为「远」，且越靠近该判断越强。因此接近围栏时由操作员人工接管
转向，对应 `ctrl_state == 'MANUAL'` 的 54 帧。

铁丝网在 RGB 画面中清晰可见，这些人工接管段包含深度管线无法提供的正确视觉判断，
对「视觉 → 操控」映射的训练具有参考价值。
