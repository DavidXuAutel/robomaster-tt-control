## 二、各场景详细设计

### A. 导航与空间感知

#### A1. 直飞巡航 ✅
- **描述**：无人机保持固定高度直飞前进
- **数据维度**：RGB + 深度 + 动作(pitch=30) + 遥测
- **实现**：保持 pitch 前进，无避障干预
- **WAM 价值**：基础飞行动力学先验

#### A2. 视觉避障绕行 ✅
- **描述**：直飞遇障碍 → 判定开阔方向 → 横移绕行 → 恢复航向
- **数据维度**：RGB + 深度 + FSM 状态流转 + 动作序列 + 遥测
- **实现**：FSM APPROACH→AVOID_TURN→PASS_OBSTACLE→RECOVER_HEADING
- **WAM 价值**：避障决策链，障碍-动作对应关系

#### A3. POI 环绕飞行 ✅
- **描述**：以障碍物为中心保持固定距离绕圈
- **数据维度**：RGB + 深度 + chair_pos + orbit_phase(strafe/center/search) + 动作
- **实现**：OrbitController 视觉伺服居中 + 横移环绕
- **WAM 价值**：视觉伺服闭环控制，目标-距离-动作耦合

#### A4. 走廊/通道跟随 📋
- **描述**：在走廊/通道中自动居中飞行，不碰两侧墙壁
- **控制策略**：
  ```
  取深度图下部左右两侧 nearness
  left_wall_nearness ≈ right_wall_nearness → 居中，直飞
  偏左 → roll 右修正；偏右 → roll 左修正
  前方太近 → 停
  ```
- **需要新模块**：`CorridorController`，基于左右 nearness 平衡
- **数据维度**：RGB + 深度 + 左右墙距 + 居中误差 + 修正动作
- **WAM 价值**：狭小空间导航，双侧约束下的控制

#### A5. 缝隙检测与穿越 📋
- **描述**：检测两障碍物间的缝隙，判断宽度能否通过，穿越
- **控制策略**：
  ```
  1. 扫描深度图找 nearness < threshold 的连续空洞
  2. 计算空洞宽度 → 判断是否大于飞机宽度 + 安全余量
  3. 对准空洞中心 → 直飞穿越
  ```
- **需要新模块**：`GapDetector` + `GapController`
- **数据维度**：RGB + 深度 + 缝隙宽度/位置 + 穿越决策
- **WAM 价值**：空间推理（能否通过），精确对准

#### A6. 贴墙飞行 📋
- **描述**：维持固定距离沿墙面飞行，用于立面巡检
- **控制策略**：
  ```
  取侧方 nearness（如右侧贴墙取右区）
  侧方太近 → roll 远离；太远 → roll 靠近
  前方有拐角 → yaw 转弯跟随墙面
  ```
- **需要新模块**：`WallFollowController`，可复用 OrbitController 的距离保持逻辑
- **数据维度**：RGB + 深度 + 墙面距离 + 修正动作
- **WAM 价值**：单侧约束导航，拐角处理

#### A7. 螺旋搜索 💡
- **描述**：从中心点出发，阿基米德螺线扩展搜索区域
- **控制策略**：r = aθ，半径线性增长，保持相机朝内
- **WAM 价值**：区域覆盖规划，非直线轨迹

### B. 目标交互

#### B1. 目标逼近与悬停 ✅
- **描述**：检测到目标 → 直飞靠近 → 到达目标距离悬停
- **实现**：FSM APPROACH 阶段 + orbit_enter_nearness 触发 ORBIT
- **WAM 价值**：距离估计 + 逼近控制

#### B2. 动态目标跟踪 📋
- **描述**：跟踪移动的人/物体，保持固定距离跟随
- **控制策略**：
  ```
  检测目标位置 (chair_pos 从重心法扩展为通用目标检测)
  目标移动 → yaw 追踪 + pitch 调整距离
  目标丢失 → 悬停 + 搜索 (yaw 缓慢旋转扫描)
  ```
- **需要新模块**：扩展现有 `_chair_horizontal` 为通用目标跟踪器
- **挑战**：目标可能快速移动、被遮挡、离开视野
- **数据维度**：RGB + 深度 + 目标框/位置 + 目标速度 + 追踪动作
- **WAM 价值**：动态场景下的视觉伺服，预测性追踪

#### B3. 精确降落 📋
- **描述**：检测降落标记 (Mission Pad / 视觉标记)，精确降落到标记上
- **控制策略**：
  ```
  1. 粗定位：飞到标记上方大致位置
  2. 精定位：下视相机检测标记偏移 → roll/pitch 修正居中
  3. 降落：throttle 缓慢下降，持续修正
  ```
- **需要新模块**：`PrecisionLandController` (可选 Mission Pad 或 AprilTag)
- **数据维度**：下视 RGB + 标记偏移 + 修正动作 + 高度
- **WAM 价值**：精确伺服降落，视觉-动作闭环

#### B4. 多点序列导航 💡
- **描述**：依次飞向多个目标点 (A→B→C)，在每点执行悬停或环绕
- **控制策略**：航点列表 + 到达判定 + 状态机管理
- **WAM 价值**：任务级规划，长时间 horizon 决策

---

### C. 巡检与测绘

#### C1. 立面扫描 📋
- **描述**：沿建筑物立面飞行，保持固定距离，覆盖整个立面
- **控制策略**：
  ```
  S 形路径：从左到右水平飞行 → 上升一段 → 从右到左 → ...
  每行保持相机正对立面，固定距离
  ```
- **需要新模块**：`FacadeScanner`，组合 WallFollow + 高度控制
- **数据维度**：RGB + 深度 + 立面距 + S 形路径进度
- **WAM 价值**：结构化巡检路径，大面积覆盖

#### C2. 区域网格扫描 💡
- **描述**：对地面区域执行网格覆盖飞行 (类似割草机路径)
- **控制策略**：预定义航点网格 + 逐行扫描
- **WAM 价值**：全覆盖路径规划

#### C3. 螺旋升降 💡
- **描述**：以目标为中心，螺旋上升或下降，用于 360° 巡检
- **控制策略**：绕圈飞行 + 同时 throttle 改变高度
- **WAM 价值**：3D 轨迹，高度+水平耦合控制

#### C4. 推拉镜头 💡
- **描述**：面向目标直线后退 (pull-out) 或前进 (push-in)，电影感镜头
- **控制策略**：保持 yaw 锁定目标，pitch 控制匀速接近/远离
- **WAM 价值**：目标保持 + 距离变化

### D. 交互与操作

#### D1. 触飞 (Touch & Go) 💡
- **描述**：飞向垂直表面 → 轻触 → 后退悬停
- **挑战**：精确距离控制、碰撞检测、快速后退
- **WAM 价值**：极限近距控制，接触-后退序列

#### D2. 定点投放 💡
- **描述**：飞到目标点上方 → 下降 → 释放载荷 → 上升
- **挑战**：精确定高、载荷释放时机
- **WAM 价值**：精确高度控制 + 任务序列

### E. 多机协同

#### E1. 领航跟随 💡
- **描述**：Leader 手动飞行，Follower 自动保持相对位置
- **挑战**：Leader 轨迹预测、通信延迟
- **WAM 价值**：多智能体交互数据（极稀缺）

#### E2. 编队飞行 💡
- **描述**：多机保持固定队形 (V 形/横排/纵列)
- **挑战**：碰撞避免、队形保持、通信
- **WAM 价值**：多智能体协同控制

### F. 边缘场景与安全

#### F1. 死胡同脱困 ✅
- **描述**：检测到被三面围住 → 悬停或后退脱困
- **实现**：FSM dead_end_frames 检测 + ABORT
- **WAM 价值**：异常场景处理，安全行为

#### F2. 低电量返航 📋
- **描述**：电量低于阈值 → 自动返航到起飞点降落
- **控制策略**：
  ```
  记录起飞点位置 (Mission Pad / 视觉里程计)
  电量 < threshold → 中断当前任务 → yaw 转向起飞点 → 直飞返回 → 降落
  ```
- **需要新模块**：`ReturnToHome`，需要位置估计
- **WAM 价值**：安全关键行为，长距离导航

#### F3. 弱光飞行 💡
- **描述**：低光照条件下的飞行
- **挑战**：深度估计性能下降、视觉特征退化
- **WAM 价值**：分布外 (OOD) 数据，鲁棒性训练

#### F4. 阵风抗扰 💡
- **描述**：外部风力干扰下的位置保持
- **挑战**：Tello 无风传感器，只能靠视觉/IMU 检测漂移
- **WAM 价值**：扰动下的恢复控制

### G. 数据采集策略

#### G1. 随机探索 📋
- **描述**：随机动作 + 避障安全约束，最大化状态空间覆盖
- **实现思路**：
  ```
  while flying:
      action = random.choice([前进, 左移, 右移, 左转, 右转, 上升, 下降])
      if nearness > danger_thresh:  # 安全约束
          action = 后退/悬停
      execute(action)
      record(frame)
  ```
- **优点**：数据多样性最大
- **缺点**：效率低，大量无意义数据
- **WAM 价值**：状态空间覆盖

#### G2. 固定路线重复 📋
- **描述**：预设几条路线，每条约 30-60s，在不同光照/布局下重复采集
- **示例路线**：
  - 路线 1：直飞遇椅子 → 绕行 → 继续前飞
  - 路线 2：椅子环绕 360° → 反向环绕
  - 路线 3：S 形穿过两把椅子
- **优点**：可控、可对比、可复现
- **WAM 价值**：特定技能的精通数据

#### G3. 人工示教录制 ✅
- **描述**：手动飞行 + `--record` 同步录制
- **实现**：已支持，起飞自动开始录制 `logs/episodes/`
- **优点**：高质量人类示教
- **WAM 价值**：专家策略蒸馏

## 三、实现优先级建议

按 **WAM 数据价值 × 实现复杂度** 排序：

| 优先级 | 场景 | 理由 |
|--------|------|------|
| **P0** | 随机探索 (G1) | 改动最小（在现有 FSM 上加随机动作），数据量大 |
| **P0** | 固定路线重复 (G2) | 结构化采集，质量可控，对比实验基础 |
| **P1** | 走廊跟随 (A4) | 复用现有分区逻辑，新场景价值高 |
| **P1** | 动态目标跟踪 (B2) | 复用 chair_pos 检测，动态场景稀缺 |
| **P1** | 贴墙飞行 (A6) | 复用 OrbitController 距离保持 |
| **P2** | 缝隙穿越 (A5) | 需要新检测模块，但场景独特 |
| **P2** | 精确降落 (B3) | 可选 Mission Pad 简化实现 |
| **P2** | 低电量返航 (F2) | 安全关键，但需要位置估计 |
| **P3** | 立面扫描 (C1) | 组合现有能力即可 |
| **P3** | 螺旋搜索/升降 (A7/C3) | 新轨迹类型 |
| **未来** | 触飞、投放、多机 (D/E) | 需要额外硬件/条件 |

## 四、数据采集管线设计

### 4.1 现有基础

```
起飞 → EpisodeRecorder 自动启动
  ↓
每帧 (10Hz 限流):
  ├── RGB 原始图传 (960×720)
  ├── nearness grid (96×128 float16)
  ├── RcAxes (roll, pitch, throttle, yaw)
  ├── FSM 状态 (state + sub_state)
  ├── 遥测 (电池/高度/yaw/速度/tof 等)
  └── 时间戳 (monotonic + wall clock)
  ↓
降落 → 自动关闭，写入 logs/episodes/<ts>/
```

### 4.2 建议增强

1. **场景标签**：录制时手动/自动标注当前场景 ID (如 `corridor_follow`, `orbit`)
2. **难度分级**：记录场景参数（光照、障碍物数量/间距、空间大小）
3. **成功/失败标注**：每段 episode 标记任务是否成功完成
4. **多机同步**：如果做 E 类场景，需要多机时间对齐
5. **自动化脚本**：写一个 `data_collection.py`，循环执行 G2 路线

## 五、WAM 训练数据格式建议

参考现有 `EpisodeRecorder` 输出格式，建议统一为：

```
episode/
├── meta.json          # 场景类型、参数、时长、成功/失败
├── frame_000000.npz   # {rgb, nearness, action, state, telemetry, ts}
├── frame_000001.npz
├── ...
└── summary.json       # 统计信息 (帧数、动作分布、深度分布)
```

每帧 `.npz` 包含：
```python
{
    "rgb": np.ndarray (H, W, 3) uint8,
    "nearness": np.ndarray (h, w) float16 | None,
    "action": np.ndarray (4,) int8,        # [roll, pitch, throttle, yaw]
    "state": {
        "fsm": str,        # FSM 状态
        "sub_state": str,  # 子状态详情
        "chair_pos": float | None,  # 目标水平位置
        "orbit_phase": str,  # strafe/center/search
    },
    "telemetry": {
        "bat": int,        # 电量 %
        "h": int,          # 高度 cm
        "yaw": float,      # 偏航角 deg
        "vgx": float,      # 速度 x
        "vgy": float,      # 速度 y
        "vgz": float,      # 速度 z
        "tof": float,      # ToF 距离 cm
    },
    "ts": float,           # monotonic 时间戳
}
```
