3. 厂商不保证产品/服务完全无缺陷、完全满足需求、永不中断，也不保证能修复全部缺陷；在法律允许范围内，对直接/间接经济损失的最大赔偿不超过客户购买该产品/服务所支付金额。

5. 厂商保留最终解释权，并可更新条款。  
6. 操作时保持机器人在视线内与安全距离；**上电后勿徒手触碰机器人**。  
7. 电池仅剩一格时，及时停止并关闭机器人，取电池充电或驶入充电桩，避免掉电倒地。  
8. 长时间待机前，将机器人置于卧倒（宇树遥控：按两次 `L2+A`）或阻尼（`L2+B`），避免低电自动关机摔倒。

### 1.2 安全消息类型

| 级别 | 含义 |
|---|---|
| 警告 | 可能导致死亡或严重伤害 |
| 小心 | 可能导致轻微或中度伤害 |
| 注意 | 重要信息，含设备或财产损坏风险 |

另：擅自损坏/更换/改装机器人或其附件，或因编程错误/故障导致的损坏，厂商概不负责。

### 1.3 一般安全注意事项

- **负载**：必须按规格放置并固定，否则可能掉落或导致倾翻。参见 [附录 6.2 产品参数 · 负载能力](#62-产品参数b2)。  
- **高速**：遥控时注意速度，高速行走可能伤人。  
- **避障**：勿过度依赖自主避障，应主动避让。  
- **坑洞 / 下行楼梯**：机器人无法可靠感知；应在地图标为禁区；合理标注上下楼梯点；及时更新地图。楼梯高度/角度参见 [附录 6.2 · 运动能力](#62-产品参数b2)。  
- **视线与距离**：保持视线可控距离；上电后勿徒手接触。  
- **待机姿态 / 低电**：见 1.1 第 7–8 条。

### 1.4 人员资质

仅合格安全人员可安装、调试、操作、维护：

- 机械安装/调试：具备专业知识与经验，能评估加装防护后的安全状态。  
- 电气安装/调试：同上（电气领域）。  
- 操作/维护：熟悉防护装置，并接受使用方指导。

### 1.5 电池低电阈值（整合后的操作约定）

原文存在两套表述，整合为分层阈值：

| 级别 | 条件 | 动作 |

## 3. 机器人与硬件（主要来自离线版）

### 3.1 机器人简介

拓普视全地形智能巡检机器人支持自主运行或远程遥控，可搭载激光雷达、超声波、红外热成像双光相机、气体监测仪、声像仪、机械臂等，用于室内外设备巡检：跑冒滴漏、泵站异响/发热、电控柜发热、仪表指针/液位计/磁翻板读数识别、区域风险监控、告警与预置故障处理。

### 3.2 电池包

#### 3.2.1 规格

| 参数 | 规格 | 备注 |
|---|---|---|
| 标称电压 | 58.8 V | 简介表述 |
| 额定供电电压 | 58 V | 规格表表述；二者并存，理解为标称/额定不同口径 |
| 额定充电电流 | 15 A | |
| 额定容量 | 18000 mAh / 932.4 Wh | |
| 运行时间 | 约 4–6 h | |
| 使用环境温度 | -5℃～55℃ | >60℃ 有起火/爆炸风险；<-10℃ 严重损害寿命 |
| 理想充电环境 | 5℃～40℃（安全指引章节） | |
| 理想存储温度 | 22℃～28℃（安全指引章节） | |

首次使用前务必充满电；必须使用官方专用充电器。

#### 3.2.2 开关机

- **开机**：关闭状态下短按电源一次，再长按 >4 s；流水灯滑过，电源绿灯常亮，电量灯显示当前电量。  
- **关机**：开启状态下短按一次，再长按 >4 s；指示灯全灭。  
- **插拔电池前必须关机**。

#### 3.2.3 放电电量指示（四灯）

放电共九档（LED1–4 组合）：87.5–100%、75–87.5%、62.5–75%、50–62.5%、37.5–50%、25–37.5%、12.5–25%、0–12.5%、=0%。

#### 3.2.4 充电流程

1. 确认交流输入 100–240 V、50/60 Hz 与充电器铭牌匹配。  
2. **先接交流电源，再接电池**。  
3. 电池须处于**关闭**状态，且须从机身**取出**。  
4. 充电中电量灯 1 Hz 闪烁指示当前电量。  
5. 运行后电池发热时，须冷却至室温再充。  
6. 原文称「电量指示灯全部熄灭表示充满」——`[原文歧义：与放电指示语义冲突，以现场硬件实际为准]`；充满后断开连接。

充电电量四档：0–25%、25–50%、50–75%、75–100%。

#### 3.2.5 充电保护指示

| 指示 | 保护项 |
|---|---|
| LED2 闪 2 次/秒 | 充电电流过大 |
| LED2 闪 3 次/秒 | 充电短路 |
| LED3 闪 2 次/秒 | 过充导致电压过高 |
| LED3 闪 3 次/秒 | 充电器电压过高 |
| LED4 闪 2 次/秒 | 充电温度过低 |
| LED4 闪 3 次/秒 | 充电温度过高 |

故障时先拔充电器，排除故障或待温度恢复后再接入。

#### 3.2.6 使用 / 存储 / 运输 / 废弃（要点）

- 禁止浸液、拆解、刺破、撞击、重压、正负极短接；禁止强磁/静电环境。  
- 禁用非官方电池/充电器、破损外壳电池、严重撞击未经官方检测的电池。  
- 起火优先：沙 → 灭火毯 → 干粉 → CO₂。  
- 长期存放：从机器人取出；防热防水；勿与金属物混放；勿耗尽后长期存放。  
- 运输前放电至约 65%；不得运输损坏电池。  
- 损坏电池彻底放电后投入指定回收，不得当普通垃圾。

#### 3.2.7 自动充电

可取出电池充电，也可机器人下蹲使底座接触充电桩自动充电。

### 3.5 日常保养与检查（离线版）

#### 清洁与存放

- 恶劣环境使用后：关机，软布清洁；重点擦多目深度相机；禁用金属刷/砂纸；清洗后擦干并吹干关节缝隙积水。  
- **清洁时勿取下电池包**（整机含电池 IP67，选配可达 IP68）——保持防护密封。  
- **长期存放**再取出电池。二者不矛盾：清洁阶段保持安装，存放阶段取出。

#### 检查

**不带电**：外观、镜头、关节/足端、螺丝、电池锁紧、水封/密封圈、散热口、足垫、电池接口、遥控器摇杆与按键。  
**上电**：遥控器功能与电量、电池电量、散热风扇有无异常剐蹭声。

### 3.6 售后（两版共有，措辞略有详略）

- 整机及相关产品保修 **1 年**（自收货日起）；可购延保。  
- 未授权私改/拆装/开壳 → 质保失效。  
- 收到坏件后承诺 **20 天内**修复或送达更换件。  
- 不可抗力、正常磨损、环境不符、使用不当、未按手册、擅自迁移/改标、未授权软硬件改造、客户基础设施原因等不适用保修。  
- 外购件不在服务范围；终端及附件一般不提供现场服务。  
- 维修可能导致数据丢失，客户须先备份。  
- **严重损坏电池包不得寄回**；若已寄回将报废且不退还。  
- 寄修邮费：客户先付；确属质量问题由厂商承担检测/材料/人工及寄回费用。

## 4. 机器人巡检平台操作

### 4.1 推荐业务主路径

```text
登录 → 确认授权/机器人在线/电量/控制权空闲
  → 地图就绪（建图或上传）→ 编辑虚拟墙/检修区 → 同步 → 发布
  → 重定位（置信度 ≥ 0.9）
  → 配置点位/动作/线路 → 任务调度
  → 自动巡检执行 → 巡检结果 / 告警确认 / 统计分析
```

离线版若与在线云端连通：策略、楼层、气体、联动设备、设备、任务管理等**不可新增**，以云端为配置主源；本地侧重监控、执行与数据上送。

### 4.2 实时监控

用途：查看视频、告警、巡检信息，并做远程控制。

**视频**

- 源切换：可见光 / 红外热成像 / 深度相机  
- 录制、语音对讲、抓拍、暂停、音量  
- 可扩展多视频通道（在线版强调）

**地图显示模式（原文术语）**

| 模式 | 原文描述 |
|---|---|
| SG | 二维平面地图状态 |
| 3D | 三维地图，可切换地图 |
| 2D | 实时卫星定位状态 |

> `[原文歧义]` SG 与 2D 边界不清；Agent 只需知道三者可切换，勿自行发明全称。

可选叠加：全部点位、点位名称、建图初始位置、3D 点云、SG 虚拟墙（红线）、SG 检修区（蓝线）。

**任务控制**

自动巡检 / 手动巡检 / 暂停 / 恢复 / 终止 / 一键返航。

**状态可读信息**

置信度、运行时长、延迟、电量、温度、急停状态、当前告警、最近任务；气体监测需先完成配置（选配）。

#### 4.2.1 远程控制（须在「手动巡检」）

| 对象 | 能力 | 限制 |
|---|---|---|
| 云台 | 上下左右、变焦、速度、方向、聚焦 | 手动巡检 + 选择云台控制 |
| 本体 | 前后、左右旋、横移、身高、速度、站立/下蹲(趴下)、爬坡步态 | 手动巡检 + 选择本体控制 |
| 急停 | — | **相当于断电** |
| 跟随 / 避障开关 | — | 跟随需配备模块 |
| 机械臂（选配） | 空间：横滚/俯仰/航向/速度；关节 J1–J6；预置：垂直展开、水平垂直、尾部垂直、教学回放 | 仅配备机械臂时可用 |

#### 4.2.2 地图导航面板

显示任务路线、机器人实时位置、巡检流程；可切换地图、查看线路闭环、在 SG 地图显示点位箭头方向。

#### 4.2.3 选配面板

- 机械臂 3D 仿真：实时姿态。  
- 气体监测：配置中勾选气体后选择搭载传感器。

### 4.3 机器人管理

#### 4.3.1 状态管理

查看实时状态、电量、开机时长、控制人。

**单一控制权**：一台机器人同一时刻仅一个控制人。释放方式：

1. APP/Web 将「手动巡检」切为「自动巡检」；或  
2. Web 实时监控页点击「释放控制」→ 机器人回到空闲。

#### 4.3.2 机器人档案

路径：`机器人巡检 → 机器人管理 → 机器人档案`

支持查看 / 新建 / 编辑 / 删除 / 条件检索；管理参数、网络、版本。

可配网络：本体 IP、可见光 IP、红外热成像 IP。  
选配详情：机械臂、气体传感器、边缘应用、电机曲线。  
任务配置：查看 / 添加 / 编辑 / 还原；支持批量删除、批量重置、单条还原。

#### 4.3.3 充电房管理

路径：`机器人巡检 → 机器人管理 → 充电房管理`  
查看 / 新建 / 编辑 / 删除充电房信息。

### 4.4 配置对象（整合后的信息架构）

原文菜单命名在两版间不一致（「基础配置」vs「配置管理」）。按 OpenAPI 与多数正文路径，统一记为：

```text
机器人巡检
├── 配置管理
│   ├── 地图管理
│   ├── 线路管理
│   ├── 点位管理（含多动作）
│   ├── 动作管理 / 动作组管理
│   ├── 区域 / 策略 / 楼层 / 气体 / 设备 / 联动设备
│   └── （在线目录）人脸识别 ← 正文缺失，见下
└── …
```

**人脸识别**：仅在线版目录出现，**正文无任何操作说明** → 标记为未文档化能力，Agent 不得假设接口行为。

#### 4.4.1 地图管理

路径：`机器人巡检 → 配置管理 → 地图管理`

能力：查看、编辑、下载、删除、检索、发布/取消、批量发布/取消/删除；离线版另有**开始建图**；在线版强调**离线上传**。

**离线本地建图步骤**

1. 无需先获取控制权 → 点「开始建图」。  
2. 选择室内 / 室外。  
3. 在确定区域左右移动；等待黑色实线加深、无明显瑕疵。  
4. 结束建图，填写地图名、区域、楼层并确认。

**建图质量要求（注意事项章）**

- 选特征明显区域；过于空旷可能失败。  
- 玻璃前用实物遮挡（激光对透明/半透明无效）。  
- 速度尽量 ≤ **0.3 m/s**。  
- 排除移动物体，保留固定物体。  
- 尽量直线行走、**90°** 转弯；从起点出发并回到起点闭环。

**编辑模式**（须先开启）

可标点、设虚拟墙与临时检修区；几何：线、矩形、圆形、多边形。

| 几何 | 画法 | 必填 |
|---|---|---|
| 线 / 多边形 | 左键逐点，双击结束 | 虚拟墙：名称；检修区：名称 + 开始/结束时间 |
| 矩形 / 圆 | 左键拖动 | 同上 |

**重定位（原文亦称「重定向」）**

1. 确认机器人实际位置。  
2. 选择地图与机器人 → 点重定位。  
3. **置信度 ≥ 0.9** 视为成功；低于此值禁止发任务。

**同步 vs 发布**

| 操作 | 含义 |
|---|---|
| 同步 | 把 PC 端虚拟墙等改动写入机器人地图源文件 |
| 发布 | 已发布地图在机器人开机时自动拉取最新改动；仅编辑未同步/未发布则开机不会用新信息 |

**优化地图**：原文称当前版本上传时会自动优化，通常无需手动。  
**全局显示**：可开关机器人坐标、雷达、指北针。

#### 4.4.2 点位管理（含多动作）

路径：`机器人巡检 → 配置管理 → 点位管理`  
（原文另有「点位（多动作）」章节，内容高度重复；整合为同一模块。）

能力：查看 / 编辑 / 配置 / 删除 / 导入 / 导出 / 检索。

保存姿态：

- 云台：水平、垂直、倍率、焦距  
- 本体：航向、俯仰、横滚、身体高度  

添加点位：用本体+云台控制到位与「幅度」后保存。巡检点可新增动作（平移、旋转、拍照、红外等），并设巡检标准。

**识别类配置**

1. **表计**  
   - 控制云台对准仪表 → 获取云台位置。  
   - 右键依次取圆周三点：最小值点 → 最大值点 → 任意圆周点（顺序不可乱）。  
   - 调内圆半径屏蔽短指针/文字干扰 → 命名保存 → 点位确认。

2. **边界**（灭火器摆放等；除液位计/表计/红外外多数检测依赖边界）  
   - 矩形或多边形画区域 → 命名确认。  
   - 声纹监测示例：点位类型「巡检点」、识别类型「声纹监测」→ 选视频通道 → 画框；参数含频率范围(kHz)、动态范围、最小声压级、校位（保持默认）、可选 PRPD、告警策略。

3. **红外测温**  
   - 识别类型选红外测温 → 矩形框选 → 命名确认。

4. **液位计**  
   - 基础信息选择 **液位计**（原文误写「液压计」，已改）。  
   - 按上限区域 **左上 → 右上 → 左下 → 右下** 四点点击 → 确认。

#### 4.4.3 线路管理

路径：`机器人巡检 → 配置管理 → 线路管理`  
查看 / 编辑 / 配置 / 删除 / 检索（在线版含导出）；可增删调整线路点位，支持路线合并。

#### 4.4.4 动作 / 动作组

## 5. 注意事项与故障处理（两版并集）

### 5.1 控制不动

**离线/平台侧**

1. 查控制主机电源是否上电。  
2. `ping` 本体 IP 是否丢包。

**在线版补充（遥控侧）**

1. 机器人/遥控器是否开机；重启遥控器；按键是否正确；是否未解除锁定。  
2. 平台侧看告警；置信度是否过低（重载地图并重定位）；是否卡在手动状态（需解除）。

### 5.2 单一控制权

见 §4.3.1。

### 5.3 控制延迟

`ping` 本体及相关设备 IP，观察 RTT 是否过高。  
在线版示例 IP：`192.168.123.76`（仅为文档示例，现场以档案配置为准）。

### 5.4 不按导航行走

相邻点间距须 > **0.5 m**，或点旁有明显参照物。

### 5.5 建图 / 重定位 / 发任务

见 §4.4.1 与 §4.5.3。  
发任务乱走：先查置信度；过低则重新加载地图后再发；正常仍异常则联系厂家。**每次发任务前看置信度。**

### 5.6 长期趴下导致定位丢失（在线）

在充电桩长期趴下可能导致定位丢失；地图加载后置信度低时，手动重定位以提高置信度。

### 5.7 摔倒处理（在线）

1. **立刻切断动力**：遥控器急停或关电源，防止电机持续受力损坏。  
2. **确认关节放松后扶正**：抓机身/提手，禁止拉腿、传感器、摄像头。  
3. 放回平整地面，按流程重启自检站立。  
4. 重启后检查外壳、关节、线缆、激光雷达。  
5. 站姿异常：连机器人 Wi‑Fi，在官方 App【设置】相关项处理（原文句子不完整；出现通讯异常告警立即联系运维）。

### 5.8 导航超时（在线）

路线被障碍阻挡且未设检修区 → 停滞并告警「导航超时，未找到有效路径」。应设置检修区及有效时间窗。

### 5.9 可见光/球机无法播放（在线）

示例可见光地址：`192.168.123.12`。先 `ping` 查丢包；异常则趴下 → 关机断电 → 查供电与交换机/5G 路由 LAN 灯。

### 5.10 反光柱 / 充电桩（在线）

1. 灰尘会削弱雷达反射，导致找不到充电桩；建议每周用柔软干布擦拭，禁用腐蚀性清洁剂。  
2. 雷达扫描扇区保持通视，勿堆放遮挡物。  
3. 勿随意移动反光柱/充电桩；移动后须通知运维重新标定。
