# 纯视觉 Aerial WAM（视觉-惯性版）：自主搜索·航迹规划·主动避障·导航

**状态：** DRAFT v2（取代 v1 的「单帧单目 + 纯拓扑」配置，家族不变、配置从 A 挪到 B）
**日期：** 2026-08-03
**存档：** v1 见 `2026-08-03-aerial-wam-pure-vision-design-v1.md`（保留，勿改）

> **目标：** 给定语义目标（文本描述或一张目标参考图），无人机在未知、部分可观环境中，**外感知仅一颗单目 RGB 相机**，自主完成目标搜索、航迹规划、主动避障与导航到达，并安全终止。

---

## 0. v1 → v2 变更摘要

v1 把全部几何压在「单目预测深度 `D̂`」这一根柱子上，带来三条致命风险：① 安全罩与世界模型共用 `D̂` → 共因失效；② 相对深度无度量尺度 → 尺度漂移；③ 纯拓扑记忆对系统性搜索与 3D 净空偏弱。

v2 的核心判断：**「RGB 相机唯一」是外感知硬约束，但飞控本就提供 IMU/姿态/高度——它们不是深度硬件、也不是经典 SLAM。** 把这些「平台已有的本体感知」纳入，用**局部窗口化视觉-惯性里程计（VIO）**（非全局 SLAM）逐条化解三风险，且几乎零硬件成本。这是纯视觉约束下性价比最高的一步。

| 变更 | v1 | v2 |
|------|----|----|
| 本体感知 | 未纳入 | **纳入 IMU/姿态/高度 + 局部 VIO** |
| 尺度 | 相对深度、脚注一句带过 | **一级决策：VIO/IMU 锚定局部度量尺度** |
| 空间记忆 | 纯拓扑 | **局部度量（秒级/数十米）嵌入全局拓扑** |
| 安全罩触发 | 主要靠 `D̂`/`p_coll`（同源） | **新增 flow time-to-contact 独立通道** |
| 深度 | 单帧 | **多帧时序 + 不确定度 + IMU 锁尺度** |
| 3D 净空 | 隐性默认 2D | **高度直读 + 局部占据体（3D）** |

## 0.5 数据/仿真前置（GO / NO-GO，先于一切）

> **本节结论优先级高于全文其余部分。** 若此前置不成立，v2 的惯性 + 稠密感知地基就是空的，任何模型 spec 都无从谈起。

### 0.5.1 静态 OpenFly 数据集能提供什么、不能提供什么

核实 `experiments/aerial/convert_openfly_to_lerobot.py` + `openfly_actions.py` + 原始标注 schema：

**原始标注每条轨迹仅有：** `scene_id, gpt_instruction, image_path, index_list, action(离散原语 id), pos(x,y,z), yaw`。

| 信号 | 静态数据集是否有 |
|------|------------------|
| 位姿真值 (x,y,z,yaw) 逐关键帧 | ✅ 有（稀疏） |
| 离散原语动作 | ✅ 有 |
| IMU（加速度/角速度） | ❌ 无 |
| 线/角速度、气压、GPS、时间戳、四元数 | ❌ 无 |
| 连续/稠密视频（可算光流的帧率） | ❌ 无 |

**更关键：动作是大跨度宏原语，帧是稀疏关键帧。** 原语跨度：前进 3/6/9 m、偏航 ±30°、升降 ±3 m；每 episode ~13 帧、帧间隔 3–9 m 一跳（`DEFAULT_FPS=10` 是写入元数据的假常数，非真实采集率）。因此：

- **VIO 喂不出来**（无 IMU 流 + 无高帧率连续图像）；
- **光流 time-to-contact 喂不出来**（帧间隔过大、视点突变）；
- **多帧稠密深度喂不出来**（基线过大、视点跳变）。

**含义：** v2 的 `[1b]`/`[1c]`/`[1d]` 三个感知模块**无法从静态 OpenFly parquet 训练或验证**。静态导出只支撑：离散原语 BC、VLN grounding、场景/指令先验——即现行方案 B 的能力范围，其 SR ≈ 10% 天花板是**数据强加的**。

### 0.5.2 缺失信号的唯一来源 = 实时物理仿真 rollout

惯性 + 稠密感知 + 碰撞信号只能从**能渲染任意视角的物理仿真器**拿，而非 parquet。核实 `experiments/aerial/eval/run_closed_loop.py`：

| Bridge | 性质 | 能否提供 v2 所需信号 |
|--------|------|----------------------|
| `MockBridge` | 纯运动学，`render()` 返回按坐标画的**占位图**（"no AirSim"） | ❌ 无真实视觉、无 IMU、无碰撞 |
| `OpenFlyBridge` | 包装 OpenFly `AirsimBridge`（"Linux + AirSim required"） | ✅ AirSim 原生给 IMU/气压/GPS/任意帧率相机/GT 深度/GT 碰撞/自由视角渲染 |

`collect_dagger.py` 用 `bridge.render()` 生成新帧，印证真渲染路径存在——**前提是 AirSim + OpenFly 的 Unreal 场景在评测主机上真能跑。**

### 0.5.3 GO / NO-GO 核查（投入 v2 前必须先跑）

**落地工具与详细判据见** `2026-08-03-aerial-sim-capability-verification-spec-v1.md` **及其实现** `experiments/aerial/sim_verify/`（**主机拓扑以该 spec 为准**：客户端 8×H100 `a25689@10.239.121.21:31126`，AirSim 渲染器 4090 `10.229.20.125:41451`——**旧写法 `:30905` 已作废**）。

从 H100 客户端执行（先按该 spec §5.3 跑 preflight/setup_env）：

```bash

cp config.env.example config.env    # 填当前主机路径/端口，勿抄旧端口
./run_all.sh                        # 退出码即判定：0=Fork A / 2=Fork A⁻ / 3=Fork B
```

核查的三层能力（sim spec §3）：① T0 RPC 连通 + SimMode；② T1 真场景 RGB（非 MockBridge 占位图）；③ T2 直连 AirSim 探 IMU/气压/GPS/碰撞/深度 GT/物理/连续帧(L2f)，**均带数值健全性**（API 可读 ≠ 信号可用）。

### 0.5.4 两条岔路（此核查结果分叉整个项目）

| | **Fork A：AirSim + 场景可用** | **Fork B：仅 parquet + MockBridge** |
|---|---|---|
| 惯性/稠密/碰撞信号 | 从 sim rollout 拿 → **v2 可行** | 全部拿不到 |
| 能做的 | model-based RL、VIO、预测式避障、闭环纠错 | **只能离线 BC 离散原语** |
| SR 上限 | 有望突破 10% | ~10%，数据钉死，任何架构都超不过 |
| v2 状态 | 继续，V0 先验证 sim 出 IMU+稠密帧+碰撞 | **v2 不可达**；需补数据采集或把目标降级回离散原语 VLN |

**决策规则：**
- **Fork A** → 进入 §7 的 V0，但 V0 的第一项改为「验证 AirSim 能稳定产出 IMU + 稠密帧 + 碰撞 + 自由视角渲染」，通过后才训练 `[1b]/[1c]/[1d]`。
- **Fork B** → **暂停 v2**。坦诚记录：纯视觉自主搜索/规划/避障在现有数据条件下不可达；要么新增一套带 IMU + 稠密视频 + 碰撞标注的采集（真机或 sim），要么把目标降级为「离散原语 VLN，SR ≈ 10%」。

**瓶颈定位：真正的瓶颈是数据/仿真底座，不是模型架构。** 在 0.5.3 核查通过前，不应再投入任何 v2 模型实现。

## 1. 问题定义

### 1.1 任务

| 能力 | 含义 |
|------|------|
| 自主寻找目标 | 目标位置事先未知；需主动探索直至视觉命中语义目标 |
| 航迹规划 | 在记忆与预测之上选择多步子目标与短程动作序列 |
| 主动避障 | 在碰撞发生前规避；含对即将进入危险构型的预判 |
| 导航到达 | 命中后接近目标并稳定终止 |

环境为 POMDP：观测局部、目标可能长期不可见，需要记忆与多步决策，而非单帧反应映射。

### 1.2 传感与系统约束（硬约束，v2 修订）

| 允许 | 禁止 |
|------|------|
| **单目 RGB 作为唯一外感知输入** | 深度相机、双目/主动深度硬件作为输入 |
| **飞控本体感知：IMU（姿态、角速度、线加速度）、气压/GPS 高度**——平台已有，非新增感知硬件 | 依赖外部深度流 |
| **局部窗口化 VIO**（几秒/数十米内度量一致，无回环、无全局 BA） | **全局 SLAM**：全局度量位姿图、回环校正后的度量轨迹作规划坐标、全局一致地图 |
| 由 RGB **预测**的单目深度 `D̂`（多帧时序、带不确定度，尺度由 VIO/IMU 锚定） | 依赖外部深度传感器恢复尺度 |
| 短时视觉运动线索（光流、time-to-contact、帧间相对运动） | —— |
| 训练/评测阶段使用仿真器特权信号（真值深度、碰撞、距离）作监督或指标 | 推理期依赖特权建图或特权位姿图 |

**关键区分（v2 立场）：**
- **局部 VIO ≠ 全局 SLAM。** 前者只在滚动窗口内保持度量一致，服务局部避障/规划/尺度；后者维护全局一致地图，被明确排除。
- **IMU/高度 ≠ 深度硬件。** 它们是飞控为「能飞」必备的本体感知，纳入不违反「外感知仅 RGB」。
- **几何分工：** `D̂` + VIO 局部度量服务**短程**避障、尺度、可通行与 3D 净空；**长程**空间结构由**全局视觉拓扑记忆**承担。

**依赖前置（须确认，分两处，见 §0.5）：**
- **训练期信号来源 = 仿真器，不是静态数据集。** 静态 OpenFly parquet **无 IMU、无稠密视频**（稀疏宏原语关键帧），惯性+稠密感知只能从 AirSim rollout 拿 → 先过 §0.5.3 GO/NO-GO 核查。
- **部署期 IMU = 真机飞控。** 平台是否向算法暴露 IMU/姿态/高度接口，飞控层面必然存在，视接口是否开放；若完全不可得，退化为 v1「单帧单目」配置并接受显著更小的安全包线（见 §9）。

### 1.3 成功判据（能力级）

过程指标优先于单一终值：

| 指标 | 含义 |
|------|------|
| 目标发现步数 / 发现率 | 搜索是否优于随机游走 |
| 近障或碰撞率 | 避障是否生效 |
| 接近过程量（匹配分、目标尺度、VIO 相对接近、或仿真特权距离） | 命中后是否在靠近 |
| 到达成功率（仿真用欧氏阈值；部署用视觉+VIO 到达判据） | 端到端任务是否完成 |
| 世界模型多步预测误差 | 想象规划是否可信 |
| VIO 局部漂移率 / 尺度一致性 | 局部度量层是否可信 |

## 2. 设计原则

1. **纯视觉外感知闭环：** 外感知只有 RGB；几何由学习预测 + 本体感知锚定，而非深度硬件或全局 SLAM。
2. **多柱几何，拒绝单柱：** 尺度靠 VIO/IMU、独立安全靠 flow-ToC、长程靠拓扑——不把避障与规划全压在 `D̂` 一根柱子上。
3. **分层决策：** 长程用拓扑（去哪一片该去的地方）；短程用世界模型想象 + 预测深度 + 局部度量代价（怎么飞过去且不撞）。
4. **世界模型进入控制回路：** 用于短程 rollout、碰撞预判与基于想象的强化学习；像素级视频预测仅用于预训练与蒸馏，不在线逐步像素规划。
5. **模式可观测：** `SEARCH` / `NAV` / `DONE` 可日志、可门禁。
6. **安全硬约束压过学习策略，且触发信号冗余：** 保守动作不交给纯价值涌现；安全罩至少有一路（flow-ToC）独立于 `D̂`。
7. **分段可验证：** 每阶段有可独立验收的子系统；未过关不叠加下一阶段。

## 4. 模块说明

### 4.1 视觉编码 `[1]`
- **输入：** 当前 RGB（及可选短历史帧）。
- **输出：** 潜变量 `z_t`，供记忆、世界模型与策略共用。
- **实现取向：** 可学习视觉 backbone 或视频/图像 VAE tokenizer；需与快世界模型的状态空间对齐。可复用 Wan2.2 VAE tokenizer。

### 4.1b 多帧单目深度头 `[1b]`
- **输入：** RGB 多帧 + `z_t` 时序上下文（借世界模型的时间先验，显著优于单帧）。
- **输出：** 稠密/半稠密深度 `D̂_t` **+ 逐像素不确定度**。
- **尺度：** 由 `[1c]` VIO/IMU 锚定为**局部度量**（见 §4.1c、§6.1）。
- **用途：** 前方/下方近障代价、短程可通行打分、目标几何旁证。
- **限制：** 纹理缺失/透明/强反光/动态遮挡下 `D̂` 不可信 → 安全罩用**不确定度膨胀后的深度**决策，并让位给 `τ`（§4.6 安全罩）。
- **训练：** 仿真真值深度 + 多帧几何一致性自监督；部署不读深度传感器。

### 4.1c 局部视觉-惯性里程计 `[1c]`（v2 新增，替代「无尺度」）
- **输入：** IMU（姿态/角速度/加速度）、气压/GPS 高度、连续视觉特征。
- **输出：** **滚动窗口内**的度量位移、速度、尺度因子、绝对高度。
- **边界：** 只做局部一致，**不做回环、不做全局 BA、不产出全局轨迹作规划坐标**（守 §1.2 禁令）。
- **作用：** 给 `D̂` 锚尺度（解风险②）；给局部占据体和 3D 净空提供度量（解风险③）；给「目标遮挡时它在哪个方位/距离」提供短时记忆。

### 4.1d 光流 time-to-contact `[1d]`（v2 新增，独立安全信号）
- **输入：** RGB 帧间光流。
- **输出：** 扩张焦点（FOE）+ 光流散度 → **碰撞时间 `τ`**。
- **关键：** **完全不经过深度回归网络**，为安全罩提供一路真正独立于 `D̂` 的触发源（解风险①共因失效）。

### 4.2 混合记忆 `[2]`（v2：局部度量 + 全局拓扑）
不做全局一致度量地图。分两层：

**局部度量层（v2 新增，秒级 / 数十米，自我中心，滚动）**
- 由 `D̂` + VIO 位移 + 高度构成的**局部占据体（3D）**。
- 用途：frontier 探索有度量依托、避障有净空体、目标遮挡期保留「方位 X 距离约 Y」。

**全局拓扑层（承 v1）**
| 元素 | 含义 |
|------|------|
| 节点 | 关键帧外观描述子 + 局部占据摘要 + 高度 + 时间戳 |
| 边 | 曾飞行可达 / 外观相似 / 策略连接 |
| 覆盖 | 已访问节点、未充分观察方向（视觉 frontier） |

- **写入：** 位移/外观变化足够时插入节点；外观匹配则加边或合并。
- **读取：** 搜索选未覆盖/高信息增益方向；导航选通向目标相关节点的拓扑路径，短程交给局部度量层。
- **明确不做：** 全局 BA、回环校正后度量轨迹作规划坐标。

### 4.3 目标 grounding `[3]`
- **输入：** 目标 descriptor + 当前观测（+ 记忆上下文）。
- **输出：** 是否命中、图像框/特征定位、置信度；命中写入「目标假设」（当前帧目标嵌入 + 关联拓扑节点 + **VIO 相对方位/距离估计**）。
- **切换：** 置信度 ≥ τ_g 且稳定若干步 → `NAV`；丢失目标 → `SEARCH`（保留最后假设 + VIO 短时方位作弱先验）。

### 4.4 快 latent 世界模型 `[4]`
- **形式：** `(z_{t+1}, p_coll, progress, done) = f(z_t, a_t)`（可含局部 `D̂`/占据条件）。
- **在线：** 对候选短动作序列想象 rollout；用 `p_coll` + 预测深度代价剔除危险序列；为 model-based RL 提供想象轨迹。
- **离线：** 由较昂贵的像素/视频预测模型蒸馏而来，或潜空间自监督。可复用 Wan2.2 视频 DiT 作预训练/蒸馏源。
- **验收（make-or-break）：** 避障质量上限 = `D̂` + 世界模型保真度上限。多步预测误差随 horizon 缓增、不发散后，才提高其在线打分权重。

### 4.5 分层决策 `[5]`
**高层（秒级）**
- `SEARCH`：子目标 = 拓扑 frontier / 信息增益最大方向（局部度量层提供 3D 净空校验）。
- `NAV`：子目标 = 目标假设关键帧或视觉伺服目标（图像位置 + 期望尺度 + VIO 相对方位）。
- `DONE`：满足到达判据或安全终止。

**中层（短程，世界模型主战场）**
- 采样/优化动作序列，在想象中最大化：接近子目标进度 − 碰撞风险 − 剧烈机动代价。
- 打分并用 `p_coll` + `D̂` 局部近障项 + 局部占据体净空。

**低层（控制周期）**
- 选中动作转连续速度/姿态指令或离散运动原语并执行。

**安全罩（硬，v2：冗余触发）**
- 触发源 = `D̂`（不确定度膨胀后） **∪** `τ`（flow-ToC，独立于 `D̂`） **∪** `p_coll`。
- 任一超阈 → 刹停/后退/悬停类保守动作。
- 任务超时、VIO 漂移异常、记忆异常、连续 grounding 抖动 → 安全模式。
- 优先级高于规划与学习策略。

### 4.6 到达与终止
部署侧组合判据：
- 目标持续可见且置信度高；
- 图像中目标尺度/对齐进入带状区间并保持；
- **VIO 相对接近速度趋近 0** 一段时间。
仿真评测另用特权欧氏距离统计成功率，与部署判据分开报告。

## 6. 关键决策（v2 提升为一级）

### 6.1 尺度约定（曾是 v1 脚注，现为一级决策）
- **选定：局部度量尺度**，由 `[1c]` VIO/IMU 锚定；`D̂` 输出与之对齐。
- 中层代价、净空判断、到达接近速度全部基于此度量尺度，而非纯表观。
- VIO 尺度不可信（长时静止、纯旋转、低纹理）时，退回纯表观 + `τ`，安全罩收紧。

### 6.2 安全罩独立信号
- 至少一路触发（`τ`）不经过 `D̂`；`D̂` 与 `τ` 同时失效的场景须列入评测集并公开。

### 6.3 3D
- 记忆、frontier、净空、避障全部按 3D 处理；高度由气压/GPS 直读，Z 向尺度不依赖单目。

## 7. 训练与分期

| 阶段 | 内容 | 过关信号 |
|------|------|----------|
| **V-1（前置）** | **过 §0.5.3 GO/NO-GO**：验证 AirSim + 场景能稳定产出 IMU + 稠密帧 + 碰撞 + 自由视角渲染 | 真渲染 RGB（非占位图）；IMU/碰撞/深度 GT 可读 → 否则停在 Fork B |
| **V0** | RGB 编码 + 多帧深度头 + VIO 打通（**信号取自 sim rollout，非 parquet**）；「目标已可见」设定下学接近与近障 | 非塌缩；接近量上升；`D̂` 尺度与 VIO 一致；简单近障生效 |
| **V1** | 快世界模型 + 短程想象规划 + flow-ToC 安全罩接入 | 碰撞率相对 V0 下降；多步 rollout 达标；`τ`/`D̂` 双通道验证 |
| **V2** | 混合记忆 + 探索策略（可先无语义，只做覆盖） | 覆盖率/再访率优于随机基线；局部度量层漂移可控 |
| **V3** | 语义 grounding，打通 SEARCH→NAV→DONE | 发现率与到达率形成基线 |
| **V4** | 世界模型想象中做 RL，真环境 rollout 校正模型 | 发现步数与到达率优于 V3，超越 BC 天花板 |

数据原则：
- BC 只提供短程飞控与「看见后怎么靠」的先验，**教不会系统性搜索**。
- 搜索与超越示教天花板靠 V2 任务设计 + V4 model-based RL。
- 深度头/碰撞头/VIO 在仿真特权信号上充分监督，再在真实 RGB 上域适应（若部署）。

## 9. 风险与缓解

| 风险 | 缓解 |
|------|------|
| 单目 `D̂` 尺度漂移、场景失效 | VIO 锚尺度；不确定度膨胀；`τ` 独立通道；失效场景入评测集 |
| VIO 漂移（纯旋转/静止/低纹理） | 窗口化限漂移；退表观 + `τ`；安全罩收紧；漂移率作监控指标 |
| 拓扑混淆（相似走廊/重复建筑） | 描述子增强、时间序边、局部度量消歧、探索强制多样性 |
| 世界模型短视或发散 | 先过 rollout 验收再加权；限想象 horizon |
| 安全罩共因失效 | `τ` 与 `D̂` 独立；同时失效场景公开 |
| 端到端过大不可调试 | 严格 V0→V4；模块可单独替换与消融 |

## 10. 物理上限与受限包线（硬件取舍的必然代价，软件补不了）

单目视觉（即便叠加 VIO）**对细线（电线/枝条）、玻璃、快速动态障碍、无纹理墙面没有硬几何保证**。这是「不上测距硬件」这一取舍的物理代价，非算法能兜底。

**可行的正确表述：在受限包线内可行——** 低速、光照/纹理良好、非对抗障碍场；安全罩极保守；公开失败模式。稠密/对抗障碍场里保证不撞，单目做不到，任务范围须据此 scope。

---

## 11. 非目标（明确不做）

- 不依赖深度传感器或预建全局度量地图。
- 不将经典/全局 SLAM 作为导航主链路（局部窗口化 VIO 除外）。
- 不在线用像素级视频模型做逐步闭环控制。
- 不把「单帧模仿学习」当作完成搜索与规划的充分方案。
- 不承诺在对抗障碍场（细线/玻璃/高速动态）中的碰撞规避保证。
